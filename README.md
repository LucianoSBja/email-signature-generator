# Generador de Firmas de Correo Electrónico

__Descripción:__

Esta aplicación web permite a los usuarios crear firmas de correo electrónico personalizadas de forma rápida y sencilla. Ofrece una interfaz intuitiva para personalizar elementos como nombre, cargo, empresa, logo, redes sociales y más. El resultado final es un código HTML limpio y listo para copiar y pegar en tu cliente de correo electrónico.

__Tecnologías Utilizadas:__
- React: Framework JavaScript para construir interfaces de usuario.
- Vercel: Plataforma de despliegue para aplicaciones web.
- Tailwind: un framework de estilos CSS


__Cómo ejecutar el proyecto localmente:__

1. __Clonar el repositorio:__

```bash
git clone https://github.com/tu-usuario/generador-firmas.git
```

2. __Instalar dependencias:__

```bash
cd email-signature-generator
npm install
```

3.__Iniciar el servidor de desarrollo:__ 

```bash
npm start
```

__Estructura del proyecto:__

- __components:__ Contiene los componentes reutilizables de la aplicación (formulario, vista previa, etc.)
- __pages:__ Contiene las diferentes páginas de la aplicación (página principal, página de configuración, etc.)
- __public:__ Contiene los archivos estáticos como el HTML principal, CSS y otros assets.
- __src:__ Contiene el código fuente principal de la aplicación.

__Funcionalidades:__

- __Personalización de la firma:__ Permite al usuario personalizar todos los elementos de la firma.
- __Vista previa en tiempo real:__ Muestra una vista previa de la firma a medida que el usuario realiza cambios.
- __Generación de código HTML:__ Genera el código HTML necesario para copiar y pegar en el cliente de correo electrónico.
- __Diseño responsivo:__ Se adapta a diferentes tamaños de pantalla.
